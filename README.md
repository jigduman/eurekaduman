# Eureka Service Registry

A Spring Cloud Eureka server learning project for service discovery in a Java microservices setup.

## Repository guide

- `ServerRegistryApplication.java`: application entry point.
- `SecurityConfig.java`: security configuration.
- `src/main/resources/application.properties`: registry configuration.
- `pom.xml`: Maven dependencies.
- `src/test/`: existing application tests.

## Development status

The original build declares Java 17, Spring Boot 2.5.6, and Spring Cloud 2023.0.1. The Spring Boot and Spring Cloud versions need compatibility review before this project should be treated as a reproducible working example.

Review the build and local security configuration before running the application. This repository preserves the original implementation and is presented as an early service-discovery exercise.
